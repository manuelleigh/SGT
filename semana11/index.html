Semana 11: Sistema de Valor del Servicio

Entregables de la sesión: Sistema web funcional con base de datos, cuadro comparativo de principios guía del SVS y mapa conceptual estructurado.

Casos Prácticos de la Sesión

Caso 01: Sistema Web con Base de Datos

Aplicación web interactiva para agendamiento de citas, atención clínica, medición de satisfacción y base de datos persistente en cliente (LocalStorage) con exportación JSON.

Abrir Sistema Web

Caso 02: Cuadro Comparativo de los 5 Principios

Matriz comparativa de los cinco principios guía del SVS: definición, objetivo estratégico, aplicación práctica en software, riesgos de omisión e indicadores de control.

Ver Cuadro Comparativo

Caso 03: Mapa Conceptual de la Sesión

Estructura taxonómica con las relaciones entre el Sistema de Valor del Servicio, concepto de valor (utilidad y garantía), principios rectores y arquetipos sistémicos.

Ver Mapa Conceptual
